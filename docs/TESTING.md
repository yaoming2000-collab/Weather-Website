# 功能测试说明

> 2026-11-03。用途：在工程化、迁移过程中确认**功能没有被改坏**。
> 这套测试是**黑盒**的：像用户一样打开网址、点击、看结果，不读内部代码。目录、函数、框架怎么改都可以，网址和用户看到的行为不变，测试就应当通过。

## 1. 三层测试

| 层 | 内容 | 命令 | 迁移后 |
| --- | --- | --- | --- |
| 单元和接口测试 | `test/`：计算规则、缓存、路由（Vitest，300 项） | `npm run check` | 依赖内部代码，重构后可能要跟着改 |
| **功能测试（本文重点）** | `e2e/`：71 条自动用例（Playwright，手机尺寸 360×800） | `npm run test:func` | **不依赖内部代码，是验收标准** |
| 人工验收 | 第 5 节：25 条，真机、真实数据、部署、广告、GA4 | 照表格逐条做 | 每次上线前做一遍 |

## 2. 怎么跑

### 本地或 Codex（默认，模拟数据，不需要联网和密钥）

```bash
npm ci
npx playwright install --with-deps chromium   # 只需一次（Codex 初始化脚本已包含）
npm run test:func                             # 约 2 分钟：自动启动本地站点（模拟数据）→ 跑全部用例
npm run test:func -- -g TC-GUESS              # 只跑一个模块
npm run test:func -- -g "TC-HOME-0[1-3]"      # 只跑几条
npm run test:func:report                      # 打开报告：失败用例有截图、操作录像（trace）
```

- 本地站点由测试自动启动：`wrangler dev --env preview --var WEATHER_PROVIDER:mock`，端口 8788（可用环境变量 `E2E_PORT` 改）。每次用一份干净的本地存储。
- 输出里如果有 `[WebServer] ... failed to lookup address information`，是本地站点在离线环境查不到 Cloudflare 的地理信息，不影响测试。
- 本地已经开着同一端口的站点时，测试会直接用它；所以本地开发时，改完代码要先关掉旧的站点再跑。

### 测真实站点（测试站、正式站，真实数据）

```bash
BASE_URL=https://weather-next.itsfunmag.com npm run test:func
```

- **只适用于模拟数据的用例会自动跳过**（下表"模式"一栏为"模拟"的），比如需要固定天气、或会写入投票数据的用例。
- 只在真实站点跑的用例（"真实"）会运行：中文搜索、县区搜索。
- 需要能访问这个网址的网络。Codex 云端执行任务时默认不能联网，要在 Codex 的环境设置里放行这个域名，或者在自己电脑上跑。
- 真实数据会变化，偶尔有一两条因为数据原因跳过（比如那个城市今天还没有题），属正常。真实站点模式会自动重试 1 次。

### 在 Codex 里怎么用

1. **环境设置**：Setup script 填 `bash scripts/codex-setup.sh`。它会装依赖、打包，并装好 Chromium。
2. **可以直接粘贴给 Codex 的任务**：

   > 运行 `npm run check` 和 `npm run test:func`。把结果整理成报告，写到 `docs/test-reports/<今天日期>.md`：
   > 通过、失败、跳过各几条；每条失败写清楚编号、现象和原因分析（看 `test-results/` 里的截图和 error-context）。
   > 判断是功能坏了还是测试需要更新。只报告，不要改代码。

   > 我改了 <模块>。先跑 `npm run test:func -- -g <TC-模块>`，失败的修好代码（不要改 e2e/ 里的预期），再跑全部功能测试，全部通过后提交。

   > 按 `docs/TESTING.md` 第 5 节生成本次上线的人工验收表，写到 `docs/test-reports/<日期>-manual.md`，每条留"通过/不通过/备注"一栏。

## 4. 测试依赖的页面标记

测试尽量用网址和看得见的文字定位，但下面这些**页面标记**（多数是 `data-*` 属性）避不开。迁移时如果改名或删除，要同步改 `e2e/` 里的测试。

| --- | --- | --- |
| `#page-data`（JSON，含 `tz`、`city.id`） | 所有城市页 | 算城市当地日期 |
